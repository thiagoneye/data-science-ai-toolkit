# Exploratory Data Analysis

## When to use

Use for perform exploratory data analysis and charts on tabular or scientific data.

## Workflow

1. Identify analytic questions and candidate variables.
2. Inspect metadata and run dataset-profiling checks.
3. Generate univariate, bivariate and group/time plots.
4. Mark confounders and potential leakage; do not claim causality.
5. Write a concise EDA narrative separating observations from hypotheses.

## Guardrails

- Do not modify raw data or access unauthorized files.
- Never invent measurements, citations, metrics, or test results.
- Honor the repository `AGENTS.md` and relevant `rules/` guidance.
- Use English identifiers/docstrings and Portuguese explanatory code comments.

## Expected outputs

EDA report, figures, descriptive tables, next hypotheses.

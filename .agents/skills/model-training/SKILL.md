# Model Training

## When to use

Use for train classical or deep learning models with reproducible configurations and checkpoints.

## Workflow

1. Inspect experiment protocol and resource constraints.
2. Check split IDs, feature pipeline and baseline.
3. Set seeds and record software/hardware versions.
4. Train with monitoring, validation, checkpointing and failure handling.
5. Save code, configuration, artifacts and experiment summary.

## Guardrails

- Do not modify raw data or access unauthorized files.
- Never invent measurements, citations, metrics, or test results.
- Honor the repository `AGENTS.md` and relevant `rules/` guidance.
- Use English identifiers/docstrings and Portuguese explanatory code comments.

## Expected outputs

Training code, config, checkpoints policy, metrics/logs.

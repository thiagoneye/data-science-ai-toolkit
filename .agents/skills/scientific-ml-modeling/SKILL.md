# Scientific Ml Modeling

## When to use

Use for design Scientific ML surrogates, PINNs, DeepONet or FNO research workflows.

## Workflow

1. Describe PDE/physics, inputs, outputs, geometry and data regime.
2. Determine whether scalar, temporal or field surrogate is appropriate.
3. Compare MLP, reduced-order models, neural operators and physics-informed constraints.
4. Plan nondimensionalization, grouped case splits and physical checks.
5. Specify baseline, ablation and out-of-distribution evaluation.

## Guardrails

- Do not modify raw data or access unauthorized files.
- Never invent measurements, citations, metrics, or test results.
- Honor the repository `AGENTS.md` and relevant `rules/` guidance.
- Use English identifiers/docstrings and Portuguese explanatory code comments.

## Expected outputs

SciML design note, model candidates, validation protocol.

# Scientific Literature Review

## When to use

Use for build a verified scientific literature matrix and identify research gaps.

## Workflow

1. Specify research question, query terms and date scope.
2. Search authorized academic sources and capture DOI/title/year/venue.
3. Verify citations against source metadata; mark unavailable texts.
4. Compare methods, datasets, assumptions, metrics and limitations.
5. Produce synthesis with references and explicit evidence gaps.

## Guardrails

- Do not modify raw data or access unauthorized files.
- Never invent measurements, citations, metrics, or test results.
- Honor the repository `AGENTS.md` and relevant `rules/` guidance.
- Use English identifiers/docstrings and Portuguese explanatory code comments.

## Expected outputs

Literature matrix, synthesis, reproducible search strategy.
